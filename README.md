# sp-forsikring-statistikk

Enkel intern frontend for Nav-ansatte som viser utbetalte summer per forsikringstype.
Konsumerer endepunktet `GET /api/utbetalinger/utbetaltesummer` i
[sp-forsikring](https://github.com/navikt/helse-sp-forsikring).

## Kjør lokalt

```bash
pnpm install
```

```bash
pnpm run dev
```

## Test

```bash
pnpm run test
```
